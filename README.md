# WaitWise

A Smart Queue Management System built with Spring Boot, React, PostgreSQL, JWT Authentication, and WebSockets.

---

## 🚀 Features

- Customer Queue Management
- Staff Dashboard
- Admin Dashboard
- JWT Authentication
- Real-time Queue Updates
- Queue Analytics
- Department Management

---

## 🛠 Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- React Router
- Axios

### Backend
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- JWT Authentication
- WebSocket
